# Parte 13: interfaz con estilo de juego de simulador (MainHud v4)

## Estilo
- Colores vivos, botones grandes con contorno oscuro y relieve.
- Icono circular a la izquierda de cada botón.
- Números con contorno, insignias rojas con "!" para avisos.
- Panel con cabecera de color y botón de cierre rojo.
- Las imágenes de referencia son de otros juegos: no se copian. Se usa el mismo lenguaje visual con formas propias.

## Otros cambios
- Estadísticas del rango en tarjetas de color (suerte, oro, gemas).
- Nivel en una insignia dorada, con barra de XP verde.
- Texto de objetivo y de misión bajados para no tapar la barra de Roblox.

## Pendiente
- Iconos propios (imágenes subidas a Roblox) en lugar de círculos.
- Animaciones (lo pediste para más adelante).

## Cómo probar
1. `rojo build` y Play.
2. Izquierda: insignia de nivel, barra de XP y cuatro botones. Derecha: monedas y cuatro botones.
3. Los textos de objetivo y misión no deben tapar la barra de Roblox.
