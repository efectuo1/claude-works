# Decisiones de diseño UI

- Móvil primero: el usuario juega desde el móvil, así que todo tiene margen de 16 px y no hay scroll horizontal.
- Sin "Próximamente" vacíos: cada sección dice algo útil o explica cuándo llega.
- Textos cortos: máximo 4 líneas por ventana, para que quepan sin cortarse.
