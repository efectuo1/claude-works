# Glosario UI

- **HUD**: botones y contadores fijos en pantalla.
- **Ventana (notice)**: panel de texto con botón ENTENDIDO.
- **Capa de diseño**: marco de 1920 x 1080 que escala con la pantalla.
- **UiAssets**: tabla con los IDs de los iconos.
