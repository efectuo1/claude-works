# Componentes FolkStudUI

Kit propio en `ReplicatedStorage/FolkStudUI.luau`:
- `H.new`, `H.rect`, `H.text`, `H.button`, `H.shadow`, `H.ink`, `H.studs`, `H.sticker`.
- `M.live(gui, handlers)` despacha botones por atributos `Action` y `Offer`.
- `M.COLOR` tiene los tonos (oro, verde, lima, rojo, rosa, ámbar, morado, azul).
- Cada ventana necesita los atributos `NeedW` y `NeedH` para que el kit calcule su escala.

Animaciones: `TweenService` con Back para entradas, Quad para barras y Quint para efectos de combate.
